## 实验配置

- Agent 代码取自 `dev@e09bba6`。TACC 启动脚本基于 `deploy/tacc@6f22b27`。官方任务、工具和评分标准来自 `tau2-bench@0c69df4`。
- 客服 Agent、模拟用户和评分模型均使用集群上的 Qwen。关闭长推理输出，客服单次模型请求超时 180 秒。原始长推理配置的试跑出现请求超时，其记录另存。
- Seed 为 42，每题一次，并发 3，上限 100 步、每题 600 秒。选取任务 0、1、2 验证端到端链路。需要完整运行才能得到 114 条全量成功率。
- 模型作业 `29185`，评测作业 `29191`。vLLM 0.26.0，双 GPU，`qwen3_xml` 工具解析，eager 模式，批次上限为 1024 tokens。

## 全量运行
