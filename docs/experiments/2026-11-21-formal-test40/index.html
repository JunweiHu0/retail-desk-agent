Method

Success is exact equality between the final episode database and the target database produced by replaying the official tau2 reference actions. The comparison scope is the task customer's user object and that customer's initial orders. Tool-call traces are recorded for diagnostics and do not determine the score. Each episode has a 600 s budget.
