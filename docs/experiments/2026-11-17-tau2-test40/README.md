## 结论

1. **TPOT 稳定在 15 ms 量级**（244 轮），解码本身没有抖动；单轮耗时差异来自生成 token 数。
2. **KV 峰值 3.2%**：40 个任务、最长 222 秒的对话也没把 11.23 GiB 的池子用起来——这个场景不需要优化 KV 容量。
3. **TTFT 405 ms 中位**，比 TPOT 的波动大，因为它包含随历史增长的 prefill。
4. **质量地板 5%**，且 6/40 的任务因用户模拟器返回空消息而失败（基础设施问题，不是模型能力问题）。
