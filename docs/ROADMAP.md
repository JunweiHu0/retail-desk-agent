# 开发范围与版本约定

- `main`：已验证的稳定版本。`v0.1.0-stable` 固定保存首次可运行的离线演示快照。
- `dev`：后续开发和模型接入分支；验证后再决定是否合入 main。
- 当前目标：桌面浏览器 Web 客服，前后端分离。
- 暂停手机端开发，不新增移动端功能或原生 App。已存在的基础响应式样式保留。
- 当前接入：DeepSeek 官方 OpenAI 兼容接口、非思考模式、单工具调用。
- 下一阶段：桌面交互、更多 Retail 查询和售后多轮任务，再运行小规模官方评测。

API Key 仅放在 WSL 本地 `.env`，不进入 Git、前端、截图或日志。
